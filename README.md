#### 2. [PixelLock — Zero-Knowledge Browser Steganography](https://github.com/rajdeepbhattacharyya25-pixel/pixel-lock)
> **Mathematical client-side data concealment in HTML5 Canvas pixel buffers and Unicode streams.**

- **Cryptographic Protocol**: In-memory AES-GCM 256-bit encryption with PBKDF2 key derivation (SHA-256, 16-byte cryptographically secure salt).
- **Binary Packaging**: Custom framing protocol `[MAGIC: PIXL] [FLAGS] [SALT] [IV] [LEN] [CIPHERTEXT] [CRC32]` preventing corruption before decryption.
- **Dual Concealment Modes**:
  1. *Least Significant Bit (LSB)*: Sequential bit alteration across RGB pixel channels ($\Delta E < 1$, imperceptible to human eyes).
  2. *Unicode Zero-Width*: Binary encoding using invisible zero-width character sequences embedded inside ordinary emojis or text strings.
- **Zero-Knowledge Principle**: Zero server calls; zero telemetry. Volatile client memory only.
- **Links**: [🌐 Live Application](https://pixel-lock.vercel.app) • [💻 Source Code](https://github.com/rajdeepbhattacharyya25-pixel/pixel-lock)
